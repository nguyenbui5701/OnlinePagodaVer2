## Wire and seat authority

The emitted snapshot schema is now **0.2.0**. Rebuild Engine and Viewer together. The current observer rejects a stale 0.1.0 snapshot. Legacy input events without `chatText` remain valid and produce no chat cue. Existing protocol fixtures and evidence retain the version they ran against.

The Engine accepts optional text from chat only. It checks both UTF-16 length ≤1,024 and UTF-8 bytes ≤2,048 before normalization. NFC, control and bidi removal, markup stripping and whitespace collapse precede the 120-grapheme cap. URLs are rendered as plain text. Invalid types and oversize inputs are rejected. Empty text carries no cue. Room/event dedup, a 650 ms room cooldown and a 3 s per-speaker cooldown bound cue output. The cue carries the accepted event ID, room and clock, sanitized text and the Engine-assigned actor/seat pair when present. Text-bearing chat can refresh a current seat. Chat without the new field retains the legacy configured spawn behavior. An unseated speaker gets a generic, nonspatial notice without display name or message content.

The existing SliceDriver additionally relays the current typed chat cue and accepts opt-in events for the community DEMO only. The Viewer checks the current actor and seat before projecting the original NameplateAnchor. There is no approved source for photos in this phase, so the effective remote allowlist is empty and every badge uses local initials or a neutral dot. HTTPS URLs are never fetched by the badge. No new icon or photo files are loaded.

Readable chat lasts 1,000–2,000 ms. The next 900 ms use a round token that shrinks, rises up to 58 CSS pixels and fades. The single chat element is reused. Gift icons use the first confirmed cue from the existing GiftFxLifecycle, the bound FXAnchor and its current actor/seat. The new overlay animates at most 3 ECO / 5 QUALITY tokens for 1,450 ms, independent of gift count. A gift transition/focus/return or text-only gift fallback takes priority over chat. Seat loss, room changes and disconnected state clear text binding. Leaving the page or losing WebGL clears the overlays. The currently active icon cue does not start over after context restore.
