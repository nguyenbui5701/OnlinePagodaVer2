# P1.0-B3D — R17B Viewer integration

`P10B3D_SA_INTEGRATION_REVIEW_REQUIRED`

The Viewer defaults to R16. `tree=r17b` opts into the locked R17B for the selected ECO or QUALITY profile. `tree=r16` and unknown values select R16. A failed R17B fetch, integrity check, parse or structure check makes one attempt to load verified R16 in the same profile. A cancelled load stops immediately. The status, console and `window.viewerReport.asset` identify the loaded revision, requested revision, profile, hash, byte length, triangle count, measured bounds and fallback reason. A failure of both assets surfaces the boot error.

## Run on Windows PowerShell

Run from the root of the integration worktree with Git, Node 24 and npm. The preview command stays running in its terminal.

```powershell
Set-Location packages/v2-events
npm.cmd ci
npm.cmd test
npm.cmd run build
Set-Location ../../apps/v2-viewer
npm.cmd ci
npm.cmd run assets:p08
npm.cmd run assets:p012b
npm.cmd run assets:p012d
npm.cmd run assets:r17b
npm.cmd test
npm.cmd run build
npm.cmd exec --offline -- vite preview --host 127.0.0.1 --port 5194 --strictPort
```

Open the all-on community DEMO. Switch `profile=eco` to `quality` for the second GLB or switch `tree=r17b` to `r16` for the comparison. [Local 720 × 1280 demo](http://127.0.0.1:5194/?demo=community&seed=9&profile=eco&look=twilight&clean=1&botanicals=on&diversity=on&blessing=on&presence=on&chatbubbles=on&gifticons=on&ambience=rich&seats=rings&shots=hero&tree=r17b)

## Acceptance results

- **66 automated tests passed** (54 Viewer, 12 Event Engine). Both builds passed. Vite reported the existing large bundle warning. The follow-up at `afa9a8b6aed760634b920e964d897147a6bcd2d0` changes only one accented character in the canvas accessibility label. The Viewer tests and build were rerun, and six further native captures across ECO/QUALITY verified valid labels and exact pixel hashes for R17B, R16 and the R16 fallback. The final evidence commit changes the runbook, evidence and an occlusion field name in the runner. [Follow-up checks](evidence/p10b3d/final-source-checks.txt) · [Native label and pixel checks](evidence/p10b3d/final-source-labels.json)
- **218 native WebGL PNGs at 720 × 1280** verified against the ledger. The R16 clean capture matched exact PR #17 pixels at all 18 OFF checkpoints and six all-on checkpoints. The no-option, explicit R16 and unknown selector paths and four independent flag combinations were exercised.
- **24 camera and event traces** cover ECO/QUALITY × seeds 9/71/1337 × 85 s idle and 66 s gifts/capacity/community. There were zero camera-segment and vertical pad hits against the active R17B mesh at the sampled positions. Worst steps were 0.1062 m cinematic and 1.4815 m during gift travel at 60 Hz. Handoff displacement was 0 m and minimum camera Y was 1.1492 m. Minimum pad separation was 4.2665 m and minimum pad-to-botanical gap was 0.4937 m. Seated contact was checked on the three real seats. DEMO gift focus stayed in A → B → C order and D remained text-only. Chat rising and the seat name were visible in the paired checks.
- **Ring visibility matched R16** across the 16–26 s sweep in all six cases. ECO seed 9 sustained the two-band criterion for 5.5 s, and the other five profile/seed pairs sustained it for 10 s. Peak unoccluded pad centers ranged from 9 to 10. Wider canopy lobes are visible in the matched high-angle images. The ray test measures the center of each pad and whole-pad visibility can vary.
- **Eight native failure/teardown cases passed** across both profiles. Missing R17B and corrupted SHA each fell back once to exactly the corresponding R16 and produced identical clean pixels. Both-fail displayed the load error. Abort performed no R16 fetch. Both WebGL context restores retained R17B and finished with WebGL error 0. Both `source=live` checks remained offline with zero real actors and gifts.
