1. Open TikTok LIVE Studio and sign in locally on the Owner's eligible account. Set the scene to portrait 9:16 and 720×1280 wherever your Studio build offers that output. Use the preview only for this check.
2. Add **Window Capture** or the compatible window source offered by Studio. Select **OnlinePagoda V2 · Portrait source**. Fit the scene proportionally and crop any Windows title bar, border or side margins. Keep diagnostics, other windows, and unrelated sources outside the preview.
3. Leave the source window open and unminimized. If Studio shows black while Edge renders correctly, reselect the app window and try the other capture method offered for the source. If available, use Display Capture on a dedicated display cropped to the clean canvas and verify the preview contains only the scene. If Edge itself is black, check the operator view and browser graphics acceleration first.
4. Inspect the moving scene in preview. Record only the scene and the nonpersonal 9:16 source/output settings as Owner Studio evidence. The Owner controls any later Go LIVE/Stop decision. Close Edge and press Ctrl+C in the Viewer terminal when finished.

## Event gateway · blocked

There is no worker startup command for this PR. `source=live` selects the disconnected Viewer path and does not open an Engine session or load a DEMO timeline, even if `demo=community` is also in the URL. It starts no event transport. Everything is local and the cost incurred was 0 VND. An approved room/source, provider license and applicable platform terms, route limits and privacy, and a reproducible read-only connection are the outstanding inputs.

Once the source is approved and reachable, the gateway boundary in Design 26 is a separate worker on 127.0.0.1 with short-lived authenticated Viewer access and strict Origin checks. The existing typed `0.1.0` Engine retains actor identity, three seats and gift FIFO. Room/connection epochs and stable event/streak identities must be verified against the provider. A redacted actual completed gift is required to confirm streak quantity/finalization, exactly-once count and the correct actor/seat camera/FX. A real session with no gift can verify connection and ordinary room events. `REAL_GIFT_END_TO_END_PENDING` applies until an actual completed gift is observed. [Design 26](https://github.com/nguyenbui5701/OnlinePagodaVer2/blob/cdd8d40/Design/26_P10B2_REAL_LIVE_STUDIO_AND_EVENT_GATEWAY.md)
