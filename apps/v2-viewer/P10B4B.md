# P1.0-B4B — Dynamic DEMO voice and Idle Blessings

`P10B4B_SA_VOICE_IDLE_REVIEW_REQUIRED`

The Viewer retains the PR #21 voice and chimes. `audio=on` exposes the operator panel. Scroll below the stage, click **Bật âm thanh**, then return to the stage with Home. `idlevoice=on` adds a seeded bell during quiet periods, with a separate bell toggle and an adjustable interval from 10 to 120 seconds. The default first interval is 20–40 s and later intervals are 25–45 s. The independent speech control indicates that its approved corpus is pending.

Idle time accrues only for visible, connected and armed cinematic playback. Accepted gift activity, pending gifts, prefetch, camera focus or return, speech, test chime and session changes prevent idle playback. Gift activity cancels any idle sound and restarts the quiet interval. The original procedural idle bell uses four pitches, a 1.4 s duration and a 30 ms preemption envelope. The original gift SFX shape and fixed Vietnamese voice remain in use.

## Rights and voice modes

**`DYNAMIC_TTS_BLOCKED`**. Upstream identifies gTTS as an unofficial wrapper around undocumented Google Translate speech functionality. The MIT license covers the library. Google's service, applicable automated access, privacy and output-use terms were checked for the proposed synthetic DEMO. No documented grant was established for this endpoint and use, so both worker and Python adapter stop before external synthesis. The separately documented Cloud API is a different service. No new names, audio or text were sent to a speech service, and no new generated speech is distributed here. [gTTS disclaimer and MIT license](https://github.com/pndurette/gTTS#disclaimer) · [Google Terms](https://policies.google.com/terms?hl=vi&gl=VN) · [Google Privacy Policy](https://policies.google.com/privacy?hl=vi) · [Distinct Cloud Text-to-Speech documentation](https://cloud.google.com/text-to-speech/docs)

The browser async adapter prefetches only on accepted final records. Exact fixture-name ID, gift enum and bounded count are the only fields sent to the local worker. On the Viewer, the request belongs to the accepted room, epoch, sequence, actor and seat. A newer coalesced final replaces the former preparation while playback eligibility still belongs to the current camera focus. The director waits at most 350 ms and only while complete fallback still fits the remaining hold. Busy, timeout, muted, stale, wrong and invalid results lead to the fixed voice or suppression. No-seat gifts use the existing nonspatial fallback policy. The programmatic QA fixture uses non-speech PCM to exercise the named and idle speech paths. Fixture sounds carry no speech provenance or rights claim.

**`IDLE_SPEECH_LIBRARY_PENDING`**. A rights-verified new 12–20 phrase Vietnamese corpus is the missing input for spoken idle blessings. Runtime idle output in this branch is the original synthesized bell. Idle does not use the gift thank-you assets. The original reference clip was unavailable for a direct listening comparison. [PR #21 voice provenance](P10B4.md) · [V1 synthesis reference](https://github.com/nguyenbui5701/OnlinePagoda/blob/9ffa2718723b11284dccdf35595c759576672f93/scripts/synthesize-stage32.py)

The separate worker binds only 127.0.0.1:5202. It checks Host, exact Viewer Origin, private in-memory bearer token, preflight, POST, JSON content type, request bytes and finite synthetic enums. It permits one running synthesis and at most four waiting. The cache is memory-only, capped at 32 entries, 8 MiB and 15 minutes, keyed by the exact synthetic name ID, template and count. The blocked executable starts without Python or network. A future reviewed activation needs verified service terms, Python, gTTS 2.5.4 and FFmpeg with `atempo`; this run verified Python 3.10.5, FFmpeg 8.1.1 and the Python adapter's blocked exit before external use.
