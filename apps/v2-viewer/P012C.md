## Exact asset inputs

`assets:p012b` reads the four Git blobs from the approved PR #10 commit. If that commit is absent locally it fetches `refs/pull/10/head` and checks its exact SHA. It checks length, SHA-256 and the GLB2 header for all four before staging. The staging tree `public/p012b/` is derived and ignored. The selected profile fetches precisely its bloom and bud. The viewer verifies bytes and hash again, then verifies the loaded mesh/primitive counts, triangles, materials, texture count and world bounds before creating the batches. Missing files identify the staging command. Same-length tampering causes load failure before producing a botanical scene.

Foreground and midground groups use authored anchor points with seed-derived yaw and at most 0.11 m jitter per horizontal axis. Each accepted placement clears the measured P02 pad radius and a conservative tree exclusion radius with a 0.22 m margin. All original plant transforms use unit scale and place the GLB root at lake Y=0.

One batch per GLB primitive reuses the original material and geometry. The two selected GLBs yield at most five additional draw calls. Materials can receive the existing QUALITY shadow. The plants add no shadow pass or external textures. Props carry only floral IDs and world transforms. Real seat occupancy, viewer count and gift focus continue to use their existing engine snapshots.

The full fixed review pair under the tree gives the trunk priority. Plants may lie outside that close frame. The screenshot index reports which floral bounding spheres lie in the frustum. ### Reproduce the evidence

Prepare a separate P0.12-A checkout at the pinned baseline. Run `npm.cmd ci` and `npm.cmd run assets:p08` in that viewer, then run these commands from the P0.12-C viewer after staging both asset sets.

```powershell
$env:V2_BROWSER = 'C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe'
$env:V2_P012A_APP = 'D:/Vibecode/onlPagodaV2/OnlinePagodaVer2/.p012a/apps/v2-viewer'
npm.cmd run evidence:p012c
```

It starts separate Vite servers on 4201 and 4202. Output defaults to `evidence/p012c`; set `V2_EVIDENCE_DIR` for a scratch run. It also checks four actual post-restore frames in each build/profile, compares the first recovered PNG hash, and records exact phase-tagged WebGL messages. The two previously observed invalid-delete messages are allowed only in teardown after deliberate context restoration, with a same-profile baseline match.
