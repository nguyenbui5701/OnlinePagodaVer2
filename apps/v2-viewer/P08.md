## Run on Windows

Install Node 24+ and Git. From the integration checkout root:

```powershell
Set-Location packages/v2-events
npm.cmd ci
npm.cmd test
npm.cmd run build
node src/demo.ts demo-trace.json

Set-Location ../../apps/v2-viewer
npm.cmd ci
npm.cmd run assets:p08
npm.cmd test
npm.cmd run build
npm.cmd run dev
```

Open `http://127.0.0.1:5173/` for cinematic with one seated preview, `?demo=gifts&clean=1` for the timed DEMO, and add `&profile=quality` for QUALITY. At 46 s, an unseen giver An triggers the first request, followed by Bình and Chi. The opening preview has no viewer identity. The engine binds the first available seat to An and creates two further instances for the burst. The browser window at 720×1280 includes the anchored gift overlays. Use a window/browser capture when the overlay is required.

`assets:p08` reads the exact pinned commits of PR #1 and #2. If the Git objects are missing, it fetches the corresponding GitHub PR refs. It verifies the four canonical binary blobs, including exact size, SHA-256 and GLB v2 header, before staging local copies in ignored `public/r16/` and `public/p08/`. The browser verifies each selected binary again before GLTFLoader parses it. Startup fails visibly if any required file is missing or changed. Runtime serves the staged files from the same origin. The build copies staged files into the distributable `dist/`; it requires no GitHub access when served. Keep it on a secure origin such as loopback to support Web Crypto.
