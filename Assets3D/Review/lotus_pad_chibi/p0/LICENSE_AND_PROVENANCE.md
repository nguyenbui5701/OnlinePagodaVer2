# Original geometry provenance — zero cost

The 3D pad and chibi meshes, material palette, native glTF node animation `sit_idle`, original seated pose and source Python were authored from scratch for OnlinePagodaVer2. Inspired by **descriptions** of the user-provided `chuav2.mp4` in Design/01, /03 and /16, but neither geometry nor textures were extracted from Roblox, commercial games, TikTok imagery or another artist's proprietary assets. The exact reference video was not accessible in this working session. No paid generation, marketplace assets, fal calls or third-party model download.

Production tooling: Python + numpy + trimesh for mesh and GLB; VTK for native GLB PBR review; PIL for review montage and animated GIF. Blender 4.5+ CPU Cycles script is supplied for the owner's separate execution. Software dependencies carry their own respective open-source licenses. Original output geometry may be commercially used by the owner, subject to compliance with tool/library terms.

No user avatar screenshots, real usernames, private LIVE data or other copyrighted visual content included. No runtime, Sakura R16 or V1 source changes. The native GLB animation is a hierarchical node track, **not a humanoid skeletal rig**; that is declared in the manifest. `.blend` files cannot be claimed until Blender actually saves them on owner Windows.
