# Original asset provenance — Sakura Hero R06

- Original 3D tree geometry authored locally with Python, NumPy, trimesh for OnlinePagodaVer2. The attached owner video `chuav2.mp4` was used only as a composition/visual reference and was not converted into textures or copied mesh geometry.
- No paid model generation, external downloaded texture, marketplace asset, branded character or Roblox mesh was used. Software: Python, numpy, trimesh, VTK, Pillow (zero-cost toolchain). No API credits used.
- Scene PBR environment lighting used for testing is procedurally generated in `render_pbr_truth.py` and NOT packed into GLB.
- R06 generator is editable source; OBJ is editable polygon mesh. Blender .blend was NOT produced and must not be declared delivered.
- Commercial use of the original asset for this project is intended. SA/owner should select the repository's distribution/license policy before third-party republication.
- R05 source and binary hashes remain immutable; R06 has its own revision and checksums.
