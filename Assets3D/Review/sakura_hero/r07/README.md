- **V1 ECO aerial:** 58 shared-lobe candidates + five centrally/edge-targeted bridge groups, recessed poly core (ECO 0.57× lobe axis instead of R06 0.90×), 2-triangle-per-petal single surfaces, upper-hemisphere coverage-aware deterministic sampling. - **V2 QUALITY aerial (~15 s):** shared golden-angle projected layout of 94 overlapping lobe layers rather than separate fan-islands, inner top coverage, reduced huge central hole, warm peach/pink shades. Still faceted at close range and not pixel-matched to video: **PARTIAL**.
- **V3 trunk (~33 s):** taller non-axial dark leader / nonuniform upper limb origins, braided curved roots, short broken irregular gold fissures. Some stylized polygonal bark and smooth branch-tube artifacts remain: **PARTIAL**.
- **B3 geometry:** retains ONE 3-triangle/petal QUALITY or 2-triangle/petal ECO sheet, with glTF `doubleSided=true` and no explicit backs. **Retained**.
- **B1 shading:** VTK native PBR with IBL and 3 fixed scene lights; control without IBL is darker. **Conditional PBR, still OPEN for Blender/Three.js**.

## Local zero-cost reproduction

Requirements Python 3.10+, `numpy`, `trimesh`. For PBR review, `vtk` and Pillow; no paid API required.

```powershell
py -m pip install numpy trimesh vtk pillow
$env:SAKURA_OUTPUT=(Get-Location).Path
py .\procedural_sakura_source.py
py .\render_pbr_truth.py .\sakura_hero.glb .\quality_top.png --view top --w 420 --h 480
py .\render_pbr_truth.py .\sakura_hero_eco.glb .\eco_top.png --view top --w 420 --h 480
```

**Reproducibility:** The output size/SHA in `BINARY_HANDOFF.md` corresponds to the generated bytes archived by AI Visual; generator fixed seed 12707. Library version and exporter may affect exact bytes on another OS; check shape/counts after rebuilding, do not overwrite a previously checksummed revision silently.
