## Cập nhật trên hai máy Windows

Dùng Node 24. Từ worktree PR #26 đã có dependencies và asset staging, dừng hai tiến trình của worktree đó trước khi chuyển. Điền HEAD đầy đủ của PR này sau khi được duyệt.

```powershell
$pagodaHead = '<HEAD đầy đủ đã duyệt>'
git fetch origin feature/v2-p10b8-r18a-world-density
git switch --detach $pagodaHead
git rev-parse HEAD
Set-Location apps/v2-viewer
npm.cmd run assets:r18a
npm.cmd run build
npm.cmd run capture:p10b2
```

Nếu máy mới, dùng phần cài sạch của [runbook trước](P10B6.md#cập-nhật-trên-cả-hai-máy-windows) và đổi branch thành `feature/v2-p10b8-r18a-world-density`. Stage `assets:p08`, `assets:p012b`, `assets:p012d`, `assets:r17b`, sau đó stage `assets:r18a` trước khi build. Chỉ giữ GLB đã xác minh trong thư mục staging. Không cần file Blend để chạy.

Mở terminal thứ hai tại root worktree:

```powershell
Set-Location packages/v2-live-gateway

```

Mở hai trang trên cùng máy. Chọn **Cây Sakura → R18a** và **Mật độ đầm sen → Dày theo cụm** rồi lưu. Khi Overlay đã dừng LIVE và nhận hết gói chờ, bấm **Áp dụng vào Overlay**. Dashboard hiện cây và mật độ thực dùng. Mặc định vẫn R17B và mật độ cũ. Nếu R18a không xác minh được, Viewer thử R17B rồi R16 cùng profile. [Dashboard](http://127.0.0.1:5189/dashboard/) · [Overlay](http://127.0.0.1:5189/overlay/)

```powershell
$pagodaVisualPath = 'packages/v2-live-gateway/data/settings.json'

git switch --detach aecc8e5399cb869fe3de95d5a7b3f15972397216
```
