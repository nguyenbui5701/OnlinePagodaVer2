## Cập nhật trên cả hai máy Windows

Máy nào cũng chạy Dashboard, Overlay và Gateway cục bộ. Trên máy thu hình, mở Overlay và LIVE Studio cùng máy. Cần Git và Node 24.

Nếu máy đã có worktree PR #24, các dependency và GLB đã stage, dừng hai tiến trình cũ của worktree đó rồi chạy tại root của worktree sạch. Thay giá trị `$pagodaHead` bằng HEAD đầy đủ của PR này trong bàn giao đã duyệt. Worktree cũ dùng lại dependency, GLB và cấu hình hình ảnh đã lưu.

```powershell
$pagodaHead = '<HEAD đầy đủ của PR CODEX 22 đã duyệt>'
git fetch origin feature/v2-p10b6-live-audio
git switch --detach $pagodaHead
git rev-parse HEAD
```

Nếu máy chưa có checkout, clone với đầy đủ lịch sử, chọn đúng HEAD và chạy phần cài đặt dưới đây. Các script asset đối chiếu blob và SHA đã khóa.

```powershell
git clone --branch feature/v2-p10b6-live-audio https://github.com/nguyenbui5701/OnlinePagodaVer2.git
Set-Location OnlinePagodaVer2
$pagodaHead = '<HEAD đầy đủ của PR CODEX 22 đã duyệt>'

Pop-Location
```

### Tùy chọn chuẩn bị lời chúc cục bộ

Nếu máy đã có thư viện PR #22, sao chép cả thư mục `vi-gtts-demo-v1` vào `apps/v2-viewer/public/audio/` trước khi build. Thư mục cần có `manifest.json` và đủ clip PCM được kê khai. Nếu cần chuẩn bị mới cho preview cục bộ, chạy từ root với Python và FFmpeg có trong PATH. Script chỉ tạo 12 câu tiếng Việt cố định đã duyệt. Cài đặt và tổng hợp theo yêu cầu chỉ diễn ra tại bước này. Giọng cảm ơn cố định có sẵn từ PR #21.

```powershell
$pagodaVoiceVenv = Join-Path $env:TEMP 'onlinepagoda-p10b4b-python'
python -m venv $pagodaVoiceVenv
$pagodaVoicePython = Join-Path $pagodaVoiceVenv 'Scripts/python.exe'
& $pagodaVoicePython -m pip install -r packages/v2-voice/requirements.txt
$env:V2_GTTS_DEMO_ENABLED = '1'
& $pagodaVoicePython packages/v2-voice/stage-idle.py
Remove-Item Env:V2_GTTS_DEMO_ENABLED
```

Bật các kênh giọng trong phiên công khai khi người vận hành có quyền dùng clip. Giấy phép dùng các clip DEMO cho phát công khai chưa được xác nhận. Kênh lời chúc báo thiếu clip hợp lệ nếu thư viện vắng hoặc sai định dạng/hash. Tiếng nước, gió, chuông lúc rảnh và chuông quà vẫn hoạt động. Viewer phát clip cục bộ và dùng câu cảm ơn chung. Tên người xem LIVE không được chuyển sang gTTS.

### Chạy trên từng máy

Terminal Gateway tại root worktree:

```powershell
Set-Location packages/v2-live-gateway
npm.cmd start
```

Terminal Viewer tại root worktree:

```powershell
Set-Location apps/v2-viewer
npm.cmd run build
npm.cmd run capture:p10b2
```

1. Mở [Dashboard](http://127.0.0.1:5189/dashboard/) rồi mở [Overlay 720×1280](http://127.0.0.1:5189/overlay/) trong cửa sổ riêng, giữ cảnh nhìn thấy.
2. Bật **Âm thanh tổng**. Tùy chọn, chỉnh từng kênh và khoảng nghỉ, để trống khoảng nghỉ nếu muốn hẹn giờ tự động. Dashboard tự lưu sau khi thả thanh kéo và hiển thị revision Overlay đã nhận.
3. Bấm trực tiếp vào cảnh 3D khi Overlay đã sẵn sàng. Web Audio chỉ phát từ cửa sổ nhận có quyền phát độc quyền và có phiên đã kết nối. Sau khi mở lại Overlay, WebGL khôi phục hoặc cửa sổ từng bị ẩn, có thể cần bấm vào cảnh để mở tiếng lại.
4. Trên máy thu hình, chọn cửa sổ Overlay và nguồn tiếng ứng dụng Desktop/browser tương ứng trong Studio. Khi có phòng được phép, nhập username và bấm **Kết nối**. Gateway hiện tại dùng localhost và không cần mã.
5. Có thể chỉnh âm thanh, tải lại hoặc đóng Dashboard giữa phiên. Các thay đổi âm thanh không cần nút **Áp dụng vào Overlay** của phần hình ảnh. Dashboard báo riêng khóa Web Audio, tắt tiếng, phiên mất kết nối và khả dụng của clip.

Âm thanh lưu tại `packages/v2-live-gateway/data/audio-settings.json` trong worktree đang chạy. Tệp được gitignore và có revision riêng. Tệp thiếu hoặc lỗi dùng mặc định tắt âm thanh tổng và tắt hai kênh giọng. Tắt tổng cắt âm ngay. Quà nhận trong thời gian tắt không được phát lại khi mở tiếng.

## Chạy lại bằng chứng

Chạy từ root worktree. Bộ test Node của worker cần Python trong PATH. Kiểm thử Web Audio dùng Edge, bản build Viewer, Gateway thật cục bộ và một nguồn sự kiện fixture. Runner mở listener riêng, dùng mặc định 5193 cho preview của fixture. Nếu Edge ở vị trí khác, đặt `V2_BROWSER`.

```powershell
node --test packages/v2-voice/worker.test.mjs
Push-Location packages/v2-live-gateway
npm.cmd test
Pop-Location
Push-Location packages/v2-events
npm.cmd test
npm.cmd run build
Pop-Location
Push-Location apps/v2-viewer
npm.cmd test
npm.cmd run build
node scripts/evidence-live-audio.mjs
node scripts/evidence-live-audio.mjs --without-idle-library
Pop-Location
```

Để chạy A/B ảnh mặc định, mở preview của PR #24 tại SHA `574e6b45b9d0db275305b0466b7761cff939b268` với `npm.cmd run capture:p10b2 -- --port 5194`. Trước khi chạy runner đầu tiên, đặt `$env:V2_FIXTURE_BASELINE_PORT = '5194'`. Hai khung dựng ở seed 9, giây 0.

120 test đạt gồm 85 Viewer, 12 Event Engine, 8 voice worker và 15 Gateway. Cả hai build TypeScript đạt, Viewer build thành công với cảnh báo kích thước chunk của Vite.

Bản build `545cdd51c1d972ef62633548234fb866bd0c9855` được kiểm tra trên Edge 158 với Intel UHD qua ANGLE D3D11. Cùng seed 9 ở khung đầu, ảnh WebGL của hai trang Overlay khớp SHA-256. Tiếng nước đổi từ 75% xuống 15% giảm RMS xuống khoảng một phần năm. Tiếng gió phát riêng. Các cửa sổ kiểm tra tắt tổng, ẩn tài liệu, mất WebGL, mất liên kết và ngắt kết nối có PCM bằng 0. Lượt giả lập lỗi mở Web Audio vẫn xác nhận 1 quà và ACK đến 2.

Bản WAV chính dài 37,632 giây, PCM16 mono 48 kHz, peak −4,53 dBFS, 0 mẫu clipping. Gift fixture ngắt lời chúc sau 38 ms, chạy một chuông và một câu cảm ơn tại focus ghế 1. Quà trùng và quà nhận khi đang tắt tiếng không phát lại. Lượt giả lập thiếu manifest báo lời chúc không khả dụng, phát chuông lúc rảnh và giữ giọng cảm ơn cố định. Chỉnh âm thanh, tải lại và đóng Dashboard giữ nguyên Overlay, revision hình ảnh và phiên nguồn. Lượt ẩn tài liệu dùng sự kiện visibility có kiểm soát. Lượt mất WebGL dùng `WEBGL_lose_context` thực của trình duyệt.
